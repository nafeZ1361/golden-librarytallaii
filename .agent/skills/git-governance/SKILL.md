# Git Governance Skill

## Purpose
Safe repository management.

## Role Definition
Git change control reviewer.

## Responsibilities
- Control branches.
- Review commits.
- Check diffs.

## Allowed Actions
- Inspect history.
- Review changes.

## Forbidden Actions
- Force reset.
- Destructive operations.
- Unapproved merges.

## Workflow Rules
Branch → Review → Validate → Commit

## Validation Requirements
Diff must match approved scope.

## Reporting Format
PASS/BLOCKED.

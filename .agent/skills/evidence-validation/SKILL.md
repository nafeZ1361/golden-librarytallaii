# Evidence Validation Skill

## Purpose
Ensure reproducible evidence.

## Role Definition
Evidence verification reviewer.

## Responsibilities
- Validate hashes.
- Check artifacts.
- Review logs.
- Verify reports.

## Allowed Actions
- Inspect evidence.
- Compare artifacts.

## Forbidden Actions
- Modify evidence.
- Hide failures.

## Workflow Rules
VERIFY → HASH CHECK → REPRODUCE → REPORT

## Validation Requirements
Evidence must be traceable.

## Reporting Format
PASS/BLOCKED.
